# Mandatary logo theme colors

The logo uses the following element colors for dark and light themes.

| Element | Dark theme | Light theme |
|---|---|---|
| M symbol | Ice `#F5F8FC` | Midnight `#101B2A` |
| Gateway | Mint `#5DE0C5` | Mint `#5DE0C5` (unchanged) |
| Lower pillars | Periwinkle `#87A9FF` | Periwinkle `#87A9FF` (unchanged) |
| Wordmark | Ice `#F5F8FC` | Midnight `#101B2A` |
| Tagline | Mint `#5DE0C5` | Deep teal `#008F7B` |
