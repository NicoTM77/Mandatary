## NIST primary-source recheck and initial mapping

On 2026-10-26, the official CSRC publication record still identifies SP 800-63B-4 as final (published 2025-07-31); its 2026-10-06 planning note links implementation resources rather than a replacement standard. Sources:

- https://csrc.nist.gov/pubs/sp/800/63/b/4/final
- https://pages.nist.gov/800-63-4/sp800-63b/aal/
- https://pages.nist.gov/800-63-4/sp800-63b/authenticators/
- https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-63b-4.pdf

The publication record was fetched live. The HTML section pages returned HTTP 403, so section numbering was checked against the official PDF rather than treating failed HTML fetches as evidence.

This is an initial mapping, **not a completed exhaustive conformance assessment**. TD §4 remains the approved design; 0.04 stays blocked until coverage and any exceptions/conflicts are explicitly reviewed.

| Requirement area | Approved design | Required evidence / open mapping |
| --- | --- | --- |
| AAL2 factors and phishing-resistant option (NIST §2.2) | TD §4.1, mandatory admin MFA; Phase 1 WebAuthn | Test password+TOTP and qualifying WebAuthn flows; distinguish user-presence-only keys from UV/multifactor flows. Optional password-only non-admin paths must not be labelled AAL2. |
| Password verifier requirements (NIST §3.1.1) | TD §4.2: 15/8 minimum, 128 maximum, blocklist, no composition/periodic expiry, hashing, paste/autofill | Boundary/Unicode/full-password comparison, compromised-password and policy-change tests.
