## How to read this

Every row has exactly one status:

* **fixed_here** — fixed in P1.18.4. Evidence names the commit, the regression test(s) (`path::name`, checked to exist) and, where a mutation run was made, the red result. A red result is a local mutation run recorded in the PR evidence; it is not a CI result.
* **already_resolved** — fixed or settled before this card by merged source. The row names the current source and the recorded acceptance. Nothing is re-opened solely from an old report.
* **bounded_limitation** — an approved, rationalised limitation. No requirement is weakened by it.
* **future_gate** — retained for a named existing card with the concrete evidence still missing. Unknown stays unknown; nothing here is a NIST/FIPS/WCAG/product-qualification claim.

Source references keep the original card, comment, run and report identifiers (`/opt/data/scratch/...` report paths are historical audit sources, not repository files). Test results for this card are in the PR evidence at the exact head; this document makes no claim that a test passed.
